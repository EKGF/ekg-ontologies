# EKGF Ontologies

An ontology family for Enterprise Knowledge Graphs, maintained by the
Enterprise Knowledge Graph Forum.

The family connects the meanings an enterprise uses with the use cases,
stories and artifacts that put them to work. Its vocabularies also describe
governance, publication and lifecycles.

## Browse the family

Open **Ontology family** in the navigation to browse the overview and the
reference page for each ontology. Follow links between terms or use search
to find a class, property or shape across the family. **PDF** opens the
complete reference as a book.

The reference includes definitions, model explanations, examples, OWL axioms
and SHACL constraints from the source ontologies. It is an editor's draft;
publication does not imply approval of an ontology release.

## Use the ontologies

Start with [Using the ontologies](using-the-ontologies.md) for namespaces,
source files and validation. The [EKG Method](https://method.ekgf.org/)
explains the use case tree and the concepts behind its stories and outcomes.

The [source repository](https://github.com/EKGF/ekg-ontologies) contains the
Turtle ontologies, registry datasets, modeling guides and tests. Each generated
publication includes a downloadable documentation graph recording its sources.
